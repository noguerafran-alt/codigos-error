# codigos-error

Guía independiente (HTML + CSS estático) de códigos de error de electrodomésticos en Argentina. Cada dato sale de un manual oficial enlazado en la página. Sin build: Render Static Site publica la raíz del repo.

`build.py` regenera los HTML.

`affiliate_links.json` alimenta el bloque de repuestos en las páginas de códigos; si `affiliate_url` está vacío, se usa el listado de Mercado Libre.
